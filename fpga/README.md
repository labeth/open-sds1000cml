# open-sds/fpga — the acq2 acquisition fabric (Cyclone IV E EP4CE10F17C8)

One default image, `default/`, built from the pad contract in `docs/acq2/01-CONTRACT.md` /
`docs/acq2/contract-161.tsv`. Layout and rules are binding in `docs/acq2/05-WORKPLAN.md`.

```
fpga/
  go.mod                 module open-sds/fpga
  Makefile               qsf | bitstream | test | sim
  internal/quartus/      headless Quartus 21.1 driver (map -> fit -> sta -> asm -> cpf), tested with fake tools
  cmd/buildfpga/         go run ./cmd/buildfpga -design default  ->  default/out/default.rbf
  common/                shared RTL (WP1b), each module with a self-checking iverilog testbench in common/sim/
  default/               THE default image (WP1b): default.v (top = default_top), *.v, default.sdc,
                         default.qsf (GENERATED), regs.vh + regmux.vh (GENERATED by ../codegen), sim/, README.md
  default/out/           build products only (git-ignored): staged sources, db/, output_files/, *.log, default.rbf
```

## The QSF is generated

`tools/portspec/qsfgen.py` turns `docs/acq2/contract-161.tsv` plus its own role table (ball -> port of
`default_top`) into `default/default.qsf`. Do not edit the QSF by hand: change the role table and run
`make qsf`; `make test` fails when the committed file drifts from the generator.

What the generator enforces (it refuses to write otherwise):

- every ball the contract lists is either assigned a port or in an explicit deliberately-unassigned list;
- no input-class ball is ever driven (02-DIFFERENTIAL §1.1, the prior branch's decisive error);
- the 80 lane balls are exactly the contract's clusters (G2 G3 G4 G5 G6, then F16), the 27 bus balls
  are exactly G1_27bit_bidir_bank2_3 in contract row order, the five singles are bidirectional class;
- electrical posture per 01-CONTRACT §7: 3.3-V LVTTL everywhere, MINIMUM CURRENT on every driven ball
  except the encode pairs and K2, no pull-ups, no bus-hold, unused balls input tri-stated, D2 (nCSO)
  reclaimed as regular IO, on-chip bitstream decompression off.

It prints the accounting each run:

```
contract balls: 170 (161 port-carrying, 7 fitter-reserved, 2 indeterminate)
assigned: 162 balls (95 in, 19 out, 48 bidir) = 159 port-carrying + 2 indeterminate (C2, B10) + 1 outside the contract (M2)
deliberately unassigned: 9 in the contract (7 fitter-reserved + 2 plan gaps: J1 B11), 9 outside (E1 M1 M15 M16 E15 E16 C1 H1 H2)
port-carrying balls accounted for: 159 assigned + 2 unassigned = 161 of 161
```

Top-level ports of `default_top` (the QSF is the authority; bit orders are documented in it):
`gpmc_d[15:0]`, `nCS1`, `nOE`, `nWE`, `sel[6:2]`, `clk` (C2), `mclk_in` (M2), `trig_sense` (A12),
`gpmc_a2`, `gpmc_b1`, `enc_p[4:0]`/`enc_n[4:0]`, `a11`, `f1`, `g1`, `g2`, `k1`, `d2`, `p6`, `k2`, `f2`,
`j2`, `bus[26:0]`, `single[4:0]`, `d1` (input), `lane[79:0]`.

Known plan gap the generator reports as `DEFECT (plan)`: J1 and B11 are input-class balls in the
contract with no role in 05-WORKPLAN §2/§3; they are left as tri-stated inputs (electrically the same as
an unread input) until the plan assigns them.

## Building the bitstream

```
cd fpga && make bitstream          # = make qsf && go run ./cmd/buildfpga -design default
```

The driver (`internal/quartus`):

1. reads `default/default.qsf`, takes `flock /tmp/open-sds-quartus.lock` (05-WORKPLAN §4.6: one flow from
   this repo at a time; a foreign `quartus_map` also lives on this host), and refuses to start with less
   than 3 GB of `MemAvailable` (`-min-free-mb`);
2. wipes `default/out/` and stages `common/*.v`, `default/*.v`, `default/*.vh`, `default.sdc`,
   `default.qsf` flat into it (so `include "regs.vh"` resolves with `SEARCH_PATH .`), writes the `.qpf`,
   and checks that the QSF's `VERILOG_FILE` list equals the staged `.v` set and that the SDC it names
   exists — a stale generated QSF or a missing SDC (unconstrained STA) is a hard error, not a warning;
3. runs `quartus_map`, `quartus_fit`, `quartus_sta`, `quartus_asm`, then
   `quartus_cpf -c -o bitstream_compression=off output_files/default.sof default.rbf`, each with its
   output in `default/out/<tool>.log`;
4. checks the rbf is exactly 368 011 bytes (the uncompressed EP4CE10 size the loader expects);
5. parses `output_files/default.fit.rpt`: the Fitter Summary (LEs, pins, memory bits, PLLs, M9Ks), the
   `I/O Assignment Warnings` table (ports the fitter had to place itself = *unassigned*), and the
   `All Package Pins` table cross-checked against every `set_location_assignment` in the QSF (a ball
   that reads `RESERVED_INPUT` instead of its port = *unused*: the port does not exist in the design);
   plus the verbatim I/O warnings (169085/169086, 15705/15706, 169064, 15714, 169177, 13024);
6. parses `output_files/default.sta.rpt`: the worst setup slack per clock across every
   `<corner> Model Setup Summary` table.

`buildfpga` prints all of that and exits 1 when any QSF pin is unassigned/unused, any clock has negative
setup slack, or the STA report has no setup summary at all — even though the rbf was written. That is
05-WORKPLAN §4.9 ("the fit must place every pin from the QSF") made mechanical.

Flags: `-design`, `-fpga-dir`, `-quartus` (default `$QUARTUS_ROOTDIR` or
`/home/labeth/intelFPGA_lite/21.1/quartus`), `-lock`, `-lock-wait` (0 = fail at once if held),
`-min-free-mb` (-1 disables the gate).

## Testing

```
cd fpga && make test               # go vet, go test ./... , qsfgen --check
```

`internal/quartus` is tested only against fake `quartus_*` shell scripts written into a temp dir: tool
order and arguments, working directory, staging (including that `common/sim/*.v` is not staged), the
stale-QSF and missing-SDC refusals, the memory gate, the flock (held by another process -> wait -> fail,
released -> run), a failing tool (flow stops, log tail in the error), a wrong-size rbf, and the report
parsers on synthetic reports in the exact Quartus 21.1 table format (verified against real
`.fit.rpt`/`.sta.rpt` files from the owned-fpga branch). Real Quartus is never launched by the tests.

## Timing and resources of the default image

Reported by `make bitstream` and recorded by WP1b/WP1c in `default/README.md` after the first real
fit (worst setup slack per clock; the PLL group must close at 200 MHz for the lane registers and the
