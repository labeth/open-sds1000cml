# fpga — the owned acquisition bitstream(s)

Module `open-sds/fpga` (Go 1.26). We **own the acquisition FPGA**: this module
holds our own bitstream design, our own FPGA↔app register/bus interface, and the
headless build tooling. The interface itself is generated by the separate
`open-sds/codegen` module (one schema → app bindings + Verilog + doc), so the
fabric and the app can never drift.

See [`standard/docs/DESIGN.md`](standard/docs/DESIGN.md) for the standard
bitstream design (§4), and [`../codegen/docs/DESIGN.md`](../codegen/docs/DESIGN.md)
for the interface schema + codegen contract (§1–§3).

## Layout

```
fpga/
├── go.mod                     module open-sds/fpga
├── fpga.go                    module-root package doc (no runtime code in Phase A)
├── standard/                  the standard (owned) bitstream design
│   ├── README.md              what it is + its register map + build
│   ├── docs/DESIGN.md         the standard bitstream design contract
│   ├── regs.vh                GENERATED  `define register header      (checked in, drift-gated)
│   ├── regmux.vh              GENERATED  write-strobe + read-mux decode (checked in, drift-gated)
│   ├── docs/REGISTER-MAP.md   GENERATED  register-map reference        (checked in, drift-gated)
│   ├── acq.v … dac.v          RTL modules                (Phase B)
│   ├── acq.qsf                device / pins / IO         (Phase B; pins bench-supplied)
│   └── acq.rbf                the built bitstream         (Phase B; bench-produced, exactly 368011 bytes)
├── internal/quartus/          headless Quartus driver     (Phase B)
└── cmd/buildacq/              assembles QSF + regs.vh, gates, compiles → acq.rbf (Phase B)
```

Future bitstream variants live as siblings of `standard/` (e.g. `fpga/<impl>/`),
each with its own README + `docs/` and its own generated `regs.vh`/`regmux.vh`
from the same schema.

## Generated interface

The four generated artifacts are produced by the `codegen` module, not here:

```
make -C codegen generate   # writes standard/regs.vh, standard/regmux.vh,
                           # standard/docs/REGISTER-MAP.md, and ../app/internal/iface/iface.go
make -C codegen drift      # fails if any is stale (the CI drift gate)
```

`standard/regs.vh` is **Verilog-2001 `` `define `` macros** (`` `include ``-able at
global scope — localparams-at-global-scope are SystemVerilog-only). The build-ID
is exposed as `` `IFACE_BUILD_ID `` plus `_LO`/`_HI` halves (you cannot part-select
a macro literal). Capture geometry (`` `REC_DEPTH ``/`` `ADDR_W ``/`` `PRETRIG_MAX ``)
comes from the schema too, so the RTL circular writer and the app agree by
construction — one geometry source.

## Build tooling (`internal/quartus` + `cmd/buildacq`)

`internal/quartus` is a pure-Go, stdlib-only headless Quartus driver. It compiles
a **multi-file** Verilog `Project` (N `.v` sources + a QSF + `` `include ``d
headers) into a Cyclone IV E `.rbf`:

```go
p := quartus.Project{
    Name: "acq", Top: "acq",       // revision / top-level entity
    QSF:      string(acqQSF),       // bench-supplied device / pins / IO
    Sources:  sources,              // acq.v, spine.v, capture.v, … (each a VERILOG_FILE)
    Includes: includes,             // regs.vh, regmux.vh (copied next to the sources)
}
if err := quartus.GateReady(2200); err != nil { … }   // refuse a 2nd flow / low RAM
rbf, err := quartus.New(work).Compile(p, out)          // map→fit→asm→cpf; must be 368011 B
```

The driver assembles the QSF (adds a `VERILOG_FILE` line per source the QSF
omits, and `TOP_LEVEL_ENTITY` / `PROJECT_OUTPUT_DIRECTORY` if absent), copies the
`` `include ``d headers into a scratch work dir (wiped on both sides),
memory-gates the flow (`GateReady` — the 3.8 GiB box OOMs on two flows), runs
`map → fit → asm → cpf`, and fails unless the result is exactly
`quartus.RBFBytes` (368011). `DefaultRoot()` is `$QUARTUS_ROOTDIR` or
`~/intelFPGA_lite/21.1/quartus`.

`cmd/buildacq` wires it to `standard/`: it reads `standard/*.v` + `standard/acq.qsf`,
resolves each source's `` `include "x.vh" `` against the design dir (where the
generated `regs.vh` / `regmux.vh` live), gates on memory, compiles, and writes
`standard/acq.rbf`, printing `OK: <path> (368011 bytes)`.

```
make bitstream        # go run ./cmd/buildacq  — bench only, NOT run in CI
make build test vet   # the Go tooling itself (CI-safe; no Quartus)
```

## Status

Phase A (this) delivers the generated interface + `standard/` scaffold. The RTL,
the Quartus driver (`internal/quartus`), and `cmd/buildacq` land in Phase B (which
does **not** run in CI — no Quartus toolchain, and the bench box runs one flow at
a time). The `.rbf` is a bench artifact.
