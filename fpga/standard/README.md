# standard — the standard (owned) acquisition bitstream

The standard bitstream is a **streaming-spine acquisition fabric** for the
EP4CE10F17C8 (Cyclone IV E): a canonical 18-bit sample spine with a programmable
decimator, a circular pre/post-trigger capture with an exact window, a trustworthy
HW trigger with an interpolating (Q16) timestamp, a **live-stream** min/max
envelope reducer, and a single DMA-shaped auto-inc `BURST` drain. It replaces the
vendor acquisition path outright — there is no vendor register map, no dual mode,
no fallback (the app refuses to drive a fabric whose build-ID differs).

Full behavior is specified in [`docs/DESIGN.md`](docs/DESIGN.md) §4 and
(clean-room) in `specs/03`.

## Register map

The register map is **generated from the schema**, not hand-maintained. See the
generated reference:

- [`docs/REGISTER-MAP.md`](docs/REGISTER-MAP.md) — the human register reference
  (blocks, selectors, fields, semantics, channels, the four frozen contracts, and
  the build-ID).

Block/selector summary (CS1 = acquisition plane, CS3 = config/control plane):

| plane | block | range | what |
|---|---|---|---|
| CS1 | `meta` | `0x10–0x17` | build-ID handshake + `VERSION` self-check |
| CS1 | `capture` | `0x20–0x2f` | `OPCODE` / `RUN` / `DECIM` / pre+post-trigger depth |
| CS1 | `drain` | `0x30–0x3f` | single auto-inc `BURST` port + `BURST_REMAIN` |
| CS1 | `status` | `0x40–0x4f` | clean level `STATUS_A` + interpolating `TRIGPOS` + `FILL` |
| CS1 | `spine` | `0x50–0x5f` | transform-stage bypass + envelope columns |
| CS1 | `channels` | `0x60–0x7f` | envelope `DATA`/`COUNT`/`RESET` triad |
| CS1 | reserved | `0x80–0xdf` | `trigger` (v1) / `measure` (v1) / `decode` (v2) |
| CS3 | `config` | `0x00–0x08` | `CONF_DONE` (never written) |
| CS3 | `frontend` | `0x09–0x3f` | LED latch + offset DACs + trigger-level DAC |

## Generated build inputs

`` `include ``d by the RTL, generated by the `codegen` module (drift-gated):

- `regs.vh` — Verilog-2001 `` `define `` macros: selectors, plane ids, field
  `_MASK`/`_LSB`, `` `IFACE_BUILD_ID(_LO/_HI) ``, and capture geometry
  (`` `REC_DEPTH ``/`` `ADDR_W ``/`` `PRETRIG_MAX ``).
- `regmux.vh` — the write-strobe + read-data decode include: `` `include `` it
  inside the top module after `regs.vh`. It generates a `we_<REG>` strobe per
  writable register and a read mux over `{rd_plane, rd_sel}`; hand RTL only
  assigns behavior behind the named `rdata_<REG>` wires, never a selector case.
  The identity/build-ID reads are driven straight from the schema.

Regenerate with `make -C ../../codegen generate`.

## Build (Phase B, bench)

`acq.v` + the module set (`spine`/`capture`/`envelope`/`drain`/`dac`) + `acq.qsf`
compile to `acq.rbf` via `cmd/buildacq` (memory-gated, headless Quartus). Pins are
bench-supplied; the shipped `.rbf` is exactly **368011** bytes with M9K preserved.
Not built in CI.
