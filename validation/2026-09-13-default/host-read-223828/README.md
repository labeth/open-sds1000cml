# Revision 10 host-read qualification

`commands.json` records the cold boot, installed-app stop, volatile FPGA/helper deployment and all tests. `results.json` contains complete counter hashes at four timing points, boundary/tail recalls, and eight raw/precision ADC trigger-alignment checks. Counter sequences are checked against independently generated bytes, not just endpoint values. Each timing override restores the prior controller setting on process exit.

`build.json` is the timing/pin audit. `rev10-qualified.tar.gz` preserves the exact generated FPGA sources, constraints, RBF and timing reports. Internal timing is closed; external SRAM/GPMC timing is supported by these device tests rather than a static board timing model.

`app-start.json`, `app-log.txt`, `app-status.json`, and `app-frame.json` record the subsequent normal-app integration. The startup full-counter gate passed at fast timing. `app-frame.bin` preserves all 524,288 unsigned Q8.8 samples per channel with an aligned hardware trigger and 32 ns sample interval. The app runs from `/dev/acq-app-host`; no scope internal permanent storage was written.

Measured DMA-call throughput at read-cycle/access/gap 10/8/5 is about 10.9 MB/s; complete warm-up/wrap recall is about 0.78 s per 2 MiB. SRAM continuation and continuous streaming remain unqualified and are not enabled by this checkpoint.
